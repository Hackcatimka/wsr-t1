# WorldSkills Blockchain Project — Earlier Version

An earlier development version of my WorldSkills blockchain competition project.

It contains a browser interface, Express server, Web3 integration and a Solidity smart contract. The final competition version is maintained in [`wsr-t1-main`](https://github.com/Hackcatimka/wsr-t1-main).

## Tech stack

- Solidity
- Web3.js
- Vue
- Node.js and Express
- HTML and CSS

## Status

Archived for project history. Use `wsr-t1-main` for the documented portfolio version and the second-place WorldSkills result.
